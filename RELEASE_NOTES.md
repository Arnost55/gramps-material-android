# Gramps Material Alpha 1.0

First public early-testing release of the unofficial native Android client for self-hosted Gramps Web.

## Included

- Connect to a self-hosted Gramps Web server and authenticate
- Tree selection, people, real-data search, profiles, and relationships
- Ancestor tree viewer
- Material 3 interface with light, dark, dynamic-color, and AMOLED themes
- App-private local caching and recent people

## Alpha notice

This is an early testing release: bugs are expected. Back up important Gramps data before using any editing feature. Alpha 1.0 should be used primarily for browsing.
